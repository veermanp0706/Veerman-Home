# Veerman Home

Home Assistant-app: één app voor je huis. Energie (Enphase-zonnepanelen en -batterij met de all-in stroomprijzen van Vattenfall FlexPrijsStroom), klimaat (Tado X via Matter), licht (Hue) en zonwering (PowerView), allemaal via Home Assistant.

Voorheen heette deze repository *Veerman-enphase*.

## Installeren

1. Home Assistant → **Instellingen → Apps → App Store**.
2. Menu rechtsboven (drie puntjes) → **Repositories** → voeg toe:
   `https://github.com/veermanp0706/Veerman-home`
3. Installeer **Veerman Home**, vul de configuratie in en start de app.

Zie [energie/DOCS.md](energie/DOCS.md) voor de instellingen.

De code bevat geen persoonlijke gegevens: IP-adres, token en tarieven vul je alleen in op je eigen Home Assistant.
