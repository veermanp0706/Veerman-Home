# Veerman Enphase

Home Assistant-add-on: een snelle app voor Enphase-zonnepanelen en -batterij, met de all-in stroomprijzen van een dynamisch contract (Vattenfall FlexPrijsStroom).

## Installeren

1. Home Assistant → **Instellingen → Add-ons → Add-on Store**.
2. Menu rechtsboven (drie puntjes) → **Repositories** → voeg toe:
   `https://github.com/veermanp0706/Veerman-enphase`
3. Installeer **Enphase energie-app**, vul de configuratie in en start de add-on.

Zie [energie/DOCS.md](energie/DOCS.md) voor de instellingen.

De code bevat geen persoonlijke gegevens: IP-adres, token en tarieven vul je alleen in op je eigen Home Assistant.
